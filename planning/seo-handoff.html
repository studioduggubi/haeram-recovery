Google은 meta keywords를 색인·순위에 사용하지 않으므로 해당 태그에 검색어를 반복하지 않았습니다. ‘인천회생’, ‘인천개인회생’도 동일한 검색 의도의 표현으로 다루되 억지 반복을 피했습니다.

운영 계정에서 남은 일

  1. Google Search Console에 https://studioduggubi.github.io/haeram-recovery/ URL 접두어 속성 추가. 소유 확인 파일·메타 태그가 발급되면 사이트에 반영.
  2. 네이버 서치어드바이저에 사이트 등록·소유 확인. 현재 프로젝트 하위 경로 등록 가능 여부와 대표 도메인 운영 방식을 실제 계정에서 확인.
  3. 사이트맵 https://studioduggubi.github.io/haeram-recovery/sitemap.xml 제출 후 수집·색인 상태 확인.
  4. 대표 검색 URL 한 개를 유지. 향후 자체 도메인을 연결할 경우 canonical·OG·JSON-LD·사이트맵을 함께 변경하고 이전 URL 이동 처리.
  5. 네이버 플레이스·기존 블로그·YouTube 설명의 사무실명·주소·전화와 홈페이지 링크 일치 확인. 순위·검색어·상담 전환을 월별로 점검.

현재 GitHub Pages는 프로젝트 하위 경로입니다. robots.txt는 도메인 루트에 있어야 하므로 하위 폴더에 파일을 둔 것으로 완료 처리하지 않았습니다. 다른 저장소의 도메인 루트 설정은 변경하지 않았습니다. Search Console·네이버 등록과 소유 확인은 아직 완료되지 않았습니다.
