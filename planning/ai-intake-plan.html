고객은 필요한 상황만 선택하고 연락 가능한 번호를 남깁니다. 해람은 접수 시각·이름·연락처·핵심 상황을 구글시트에서 보고, 이메일 알림을 받아 바로 다음 연락을 이어갑니다. 별도 관리자 사이트는 만들지 않습니다.

고객에게 보이는 것은 세 화면

① 지금 가장 걱정되는 일

매달 상환 부담 / 독촉·압류 / 법원 문서·기한 / 회생·파산을 알아보는 중. 하나만 고르면 다음으로 갑니다.

② 첫 연락에 필요한 두 가지

소득: 정기 / 불규칙 / 거의 없음.
채무: 3천만원 미만 / 3천만~1억원 미만 / 1억원 이상 / 잘 모르겠음.

정확한 금액이나 증빙을 요구하지 않습니다. 이 선택으로 신청 자격이나 수임 가능 여부를 판정하지 않습니다.

③ 연락받을 번호

전화번호는 필수입니다. 불러드릴 이름은 선택이며 별칭도 가능합니다. 연락받기 편한 시간은 선택 항목으로 둡니다. 번호 형식을 확인하고, 제출 전에 고객이 번호를 다시 볼 수 있게 합니다.

선택한 세 가지 핵심 상황을 바로 보여주고, 수집 목적·항목·보관 기간 안내와 동의 후 ‘이 내용으로 전화 상담 요청하기’를 누릅니다.

형식 검사는 실제 통화 가능 여부를 보장하지 않습니다. 문자 인증을 추가하면 확인은 강해지지만 이탈·비용이 늘므로, 초기 흐름은 입력 실수 확인과 명확한 연락 안내에 집중합니다.

안심은 짧고 분명한 안내로

“연락처는 마지막에 남겨요. 상담 요청을 누르기 전에는 사무실로 전달하지 않아요.”
“해람법무사에서 상담 연락을 드리기 위한 번호예요.”
“정확한 금액이나 서류는 지금 필요 없어요.”

주소·생년월일·주민등록번호·계좌·채권자별 상세 내역·서류 첨부를 초기 화면에서 요구하지 않습니다. 선택 도중 자동으로 사무실에 저장하지 않고, 최종 제출한 정보만 접수합니다. 동의를 미리 체크하지 않고 상담과 관계없는 마케팅 동의를 묶지 않습니다.

추가로 할 말은 필요할 때만 선택 항목으로 둡니다. AI는 이 짧은 사연을 정리하는 용도로 붙일 수 있으며, 선택 답변과 원문을 보존합니다. 기본 접수는 AI 응답을 기다리지 않고 완료되도록 설계합니다.

구글시트에서 해당 접수 확인 →

메일 본문은 바로 연락하는 데 필요한 짧은 정보로 구성합니다. 구글시트는 사무실이 허용한 계정만 열람하며 공개 링크로 배포하지 않습니다. 접수 ID로 중복 저장을 막고, 시트 저장 후 알림을 보내며 발송 실패는 시트에 표시하고 재시도합니다.

구현 범위와 현재 상태

웹사이트의 브랜드 화면 → 접수 처리 → 구글시트에 행 추가 → 두 주소로 메일 알림. 구현 후보는 사무실 소유 구글시트 + Google Apps Script입니다. 고객이 따로 구글 계정에 로그인하지 않는 흐름으로 연결합니다.

현재는 기획·화면 미리보기까지입니다. 실제 접수 시트와 Apps Script 실행 계정 연결, 메일 권한, 보관 기간·안내 문구는 운영 연결 단계에 필요합니다. 번호 없이 완료할 수 없도록 미리보기에도 필수 입력과 형식 검사를 적용했습니다.

실제 접수 완료 화면은 서버의 시트 저장 성공을 받은 뒤에만 보여줍니다. 메일 발송이 늦거나 실패해도 접수 행은 남기며, 제출 실패 시 입력 내용을 유지하고 재시도·전화 연결을 제공합니다.
