# 해람 법무사 개인회생·개인파산

개인 고객용 반응형 랜딩페이지입니다. 기존 상속 사이트와 별도로 운영합니다.

- 공개 주소: https://studioduggubi.github.io/haeram-recovery/
- HTML / CSS / JavaScript, 빌드 의존성 없음
- 4문항 상담 준비 메모: 브라우저 안에서만 처리, 서버 전송·저장 없음
- 상담: 기존 공식 카카오톡과 대표전화로 연결
- 공개된 실제 브랜드 이미지·대표 경력만 사용. 후기·성공률·가격 수치를 임의로 만들지 않음

로컬 미리보기: `python3 -m http.server 4173 --bind 127.0.0.1`

GitHub Pages는 main 브랜치의 루트에서 배포합니다. 브랜딩 이미지와 콘텐츠의 권리는 해람법무사 사무소 등 각 권리자에게 있습니다.
