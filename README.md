# 해람 법무사 개인회생·개인파산

공개 주소: https://studioduggubi.github.io/haeram-recovery/

개인 고객 전용 반응형 랜딩페이지. 기존 상속 사이트는 별도로 유지합니다.

## Visual edition

- 해람 캐릭터를 참고해 Higgsfield GPT Image 2.5로 만든 설명용 3D 일러스트 3장
- Figma 원본의 실제 프로필·브랜드 소품 촬영 사진 2장
- 23종 SVG 아이콘, 회생·파산 단계 표시, 4단계 진행 안내
- 자세한 제도 설명은 펼침 UI로 제공
- 상담 준비 질문은 연락처 수집이나 서버 전송 없이 브라우저 안에서만 처리
- 기존 공식 카카오톡·대표전화로 상담 연결

HTML/CSS/JavaScript로 구성하며 별도 빌드 의존성은 없습니다. `python3 -m http.server 4173 --bind 127.0.0.1`로 미리볼 수 있습니다.

Pages: main 브랜치 루트. 이미지와 콘텐츠 권리는 해람법무사 사무소 등 각 권리자에게 있습니다. 생성 일러스트는 안내용 그림이며 실제 사건 결과를 나타내지 않습니다.
